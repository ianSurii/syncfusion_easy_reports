syncfusion_easy_reports

Professional, model-driven Excel (.xlsx) and PDF reporting engine for Flutter. Define columns, calculations, and grouping once—render accurately across platforms.

🚀 Open Interactive Web Demo 📦 View on pub.dev ⭐ GitHub Repo

Core Architecture: Define Once, Export Everywhere

🎯 Model-Driven Schema

Pass custom Dart classes (Employee, Invoice, Order) or JSON-like maps through typed column selectors with automated type normalization.

📊 Multi-Analysis Engine

Generate detailed listings, single/multi-field grouping, custom aging buckets, Top-N rankings, and 2D cross-tabulation pivot tables from one dataset.

🔐 Security & Financial Accuracy

Formula injection protection, reconciliation auditing, high-precision decimal rounding, workbook password protection, and encrypted PDFs with permission flags.

Quick Start Example

import 'package:syncfusion_easy_reports/syncfusion_easy_reports.dart';

// 1. Define Reusable Report Schema & Analyses
final definition = ReportDefinition<Employee>(
  title: 'Monthly Compensation Audit',
  columns: [
    ReportColumn.text(id: 'id', title: 'Employee ID', value: (e) => e.id),
    ReportColumn.text(id: 'dept', title: 'Department', value: (e) => e.department),
    ReportColumn.money(id: 'netPay', title: 'Net Pay', currencyCode: 'USD', value: (e) => e.netPay),
  ],
  analyses: [
    ReportAnalysis.detail(id: 'register', title: 'Payroll Register'),
    ReportAnalysis.grouped(
      id: 'departments',
      title: 'Department Summary',
      groupBy: ['dept'],
      measures: [
        ReportMeasure.count(id: 'headcount'),
        ReportMeasure.sum(column: 'netPay', currencyCode: 'USD'),
        ReportMeasure.average(column: 'netPay', title: 'Avg Net Pay', currencyCode: 'USD'),
      ],
    ),
  ],
);

// 2. Prepare & Generate Standalone Bytes (Zero UI Dependency)
final engine = ReportEngine();
final prepared = await engine.prepare(definition: definition, records: employeeList);

final excelArtifact = await engine.exportExcel(prepared);
final pdfArtifact = await engine.exportPdf(prepared);

// 3. Save or Download (Cross-Platform)
await ReportSaver().save(excelArtifact);
